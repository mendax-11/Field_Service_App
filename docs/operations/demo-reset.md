# Demo Data Reset

For the sample-data demo, reset browser state from the application settings or by clearing the TimberFlow keys below:

- `fsa_orders`
- `fsa_carpenters`
- `fsa_payout_ledger`
- `fsa_sync_queue`
- `fsa_logged_in_user`
- `fsa_user_role`

Do not clear unrelated browser storage when testing alongside other applications.
